# Employee Attrition Prediction Using Decision Tree Classification

## Project Overview
This project uses Machine Learning to predict employee attrition (whether an employee leaves or stays at a company) using a Decision Tree Classification algorithm.

## Objectives
- Analyze employee data.
- Preprocess data for Machine Learning.
- Train a Decision Tree classification model.
- Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.
- Visualize the decision tree and demonstrate predictions.

## Technologies Used
- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
IBM HR Analytics Employee Attrition dataset, containing employee information and an `Attrition` target column.

## Methodology
1. Load and explore the dataset.
2. Clean and preprocess the data.
3. Encode categorical variables.
4. Split the data into training and testing sets.
5. Train the Decision Tree classifier.
6. Generate predictions and evaluate model performance.
7. Visualize the results.

## Results
The model's accuracy, classification report, confusion matrix, and decision tree visualization are included in the project notebook.

## How to Run
1. Download the notebook `employee_attrition_prediction.ipynb`.
2. Open it in Google Colab.
3. Run the cells in order.

## Disclaimer
Predictions are estimates based on historical data and should not be used as the sole basis for employment decisions.
